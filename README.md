# Telegram-бот для продажи VPN

Бот на **aiogram 3** с инлайн-кнопками: выбор тарифа → оплата → автоматическая выдача VPN-конфига.

## Возможности

- Меню с кнопками: «Купить VPN», «Мои ключи», «Помощь»
- Несколько тарифов (задаются в `config.py`)
- Два режима оплаты:
  1. **Telegram Payments** (кнопка «Оплатить», если задан `PAYMENT_PROVIDER_TOKEN`) — оплата картой прямо в Telegram, автоматическая выдача ключа сразу после платежа.
  2. **Ручное подтверждение** (кнопка «Я оплатил») — пользователь переводит деньги по реквизитам, админ получает уведомление с кнопками «Подтвердить»/«Отклонить», после подтверждения ключ выдаётся автоматически.
- Хранение заказов, пользователей и выданных ключей в SQLite.
- Пул готовых VPN-конфигов (`/addkeys`), из которого ключи выдаются по очереди.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`:
- `BOT_TOKEN` — токен от @BotFather
- `ADMIN_IDS` — ваш Telegram id (узнать через @userinfobot)
- `PAYMENT_PROVIDER_TOKEN` — если хотите принимать оплату картой прямо в Telegram (получить у @BotFather → Bot Settings → Payments, нужен договор с платёжным провайдером, например ЮKassa/Тинькофф). Оставьте пустым для режима ручного подтверждения.

## Запуск

```bash
python bot.py
```

## Как добавить VPN-конфиги в пул

Отправьте боту сообщение со списком конфигов (по одному в строке), затем **ответьте** на это сообщение командой:

```
/addkeys
```

Конфиги добавятся в пул и будут выдаваться пользователям по очереди при оплате. Если пул пуст, бот выдаёт временную заглушку — обязательно замените функцию `generate_placeholder_config()` в `bot.py` интеграцией с вашей VPN-панелью (Outline Manager API, Marzban, 3x-ui, WireGuard-скрипт и т.д.), чтобы конфиги генерировались автоматически.

## Важно

- Это рабочий каркас — перед продакшеном добавьте: логирование в файл, резервное копирование БД, реальную интеграцию с VPN-сервером, обработку возвратов/споров.
